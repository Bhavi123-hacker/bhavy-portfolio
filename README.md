## 📖 About

This repository contains the source code for my personal portfolio website, built to showcase my journey as a Software Engineer and Machine Learning enthusiast.

The portfolio highlights my projects, technical skills, certifications, internship experience, coding profiles, leadership roles, and detailed engineering case studies. It is designed with a modern UI, premium animations, and a fully responsive layout.

---

## ✨ Features

- 🎨 Modern responsive UI
- ⚡ Built with React + TypeScript + Vite
- 🌙 Dark theme with Neon Green design system
- 🎥 Smooth animations using Framer Motion
- 📚 Detailed project case studies
- 💻 Coding profile section
- 📊 GitHub integration
- 📄 Resume download
- 📬 Contact form with EmailJS
- 🚀 Optimized for performance and responsiveness

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Bhavi123-hacker/bhavy-portfolio.git
```

Navigate into the project

```bash
cd bhavy-portfolio
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Create production build

```bash
npm run build
```
